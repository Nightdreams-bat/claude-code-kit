---
description: Print a clean, high-level file tree of the thing we're discussing, in a code block. Usage: /file-tree [path]
---

The argument is: `$ARGUMENTS`

Give a nice file tree, inside a code block, of the thing we're talking about (or `$ARGUMENTS`
if given). Just the high-level structure. If there are many files or subfolders, show only the
main ones. Don't overwhelm — keep it simple. One or two lines of annotation per top-level entry
is fine; no more.
