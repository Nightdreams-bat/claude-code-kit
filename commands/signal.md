---
description: Pull the passages from an expert's real work that hit your exact situation, plus where they show you're wrong. Usage: /signal <expert> on <topic>
---

The argument is: `$ARGUMENTS`

Load the `signal-from-expert` skill and run it.

1. Establish the corpus (the user's raw thinking — ask if not obvious; check the vault too),
   the expert, and the topic from `$ARGUMENTS`.
2. Read the corpus in full. State the user's real situation in 2–3 sentences.
3. Find and fully read 5–8 primary sources from the expert (`WebSearch` + `WebFetch`).
4. Report only the passages that change what the user should do — verbatim quotes + source +
   how each applies to the corpus.
5. Name at least one gap where the expert shows the user is wrong or missing something. Required.
6. Short synthesised read-out. Save it to the vault.
